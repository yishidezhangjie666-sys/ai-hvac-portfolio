# AI + 建环专业作品集

## 关于我

建筑环境与能源应用工程专业学生，正在学习使用 ChatGPT、Codex 和基础编程工具，将专业学习、课程设计、工程计算、文档审查和项目协作中的实际问题整理成可验证的小型工具与工作流。

## 作品集主线

这不是单纯堆积 AI 工具，也不是训练大模型；重点是把 AI 用于真实建环和学习场景。每个项目都提供样例、截图、测试或验收记录，以及边界说明。本人负责需求、专业规则、验收标准和最终判断。

## 三个重点项目

### 1. 建环工程计算工具箱

一句话定位：面向学习与课程设计辅助的通风风管和空调水系统水力计算工具。

- 解决的问题：把常见水力计算、结果查看和导出流程整理为可重复使用的小工具。
- 核心功能：通风风管水力计算、空调水系统水力计算、CSV/Excel/Word 导出与 Streamlit 页面。
- 本人承担：需求定义、建环专业规则、验收与项目边界。
- AI 辅助：编码、查错和文档整理。
- 验证证据：已验证的测试、CI 与 Release 记录；最新 Project Checks #24 已确认通过。
- 项目边界：不替代天正、鸿业、广联达等专业软件；不作为正式工程审图依据。

[查看项目详情](projects/hvac-toolbox.md) · [GitHub](https://github.com/yishidezhangjie666-sys/hvac-duct-hydraulic-calculator) · [Streamlit](https://hvac-mep-calc-toolbox.streamlit.app/)

Streamlit 部署已确认可访问；应用可能因休眠需要先唤醒。

### 2. 建环资料审查器

一句话定位：为建环课程设计说明书提供明显问题提醒的 `.docx` 审查工具。

- 解决的问题：提示格式、单位、公式说明与专业逻辑中的明显风险。
- 核心功能：生成审查结果总览、问题类别和项目边界说明。
- 本人承担：审查范围、专业判断、验收标准与最终复核。
- AI 辅助：本项目不接入 AI；展示材料仅用于说明工作流。
- 验证证据：公开合成样例、实际生成的审查输出、pytest 与验收证据。
- 项目边界：不自动修改 Word、不替代人工审查、不作为正式工程审图依据。

[查看项目详情](projects/docx-checker.md)

当前仅展示脱敏项目说明和截图，源代码仓库暂未公开。

### 3. ChatGPT + Codex 可移植、可审计交接证据层

一句话定位：建立在 Codex 原生能力之上的 Markdown-first 交接证据整理层。

- 解决的问题：在项目交接时保留可读、可核验的摘要、清单、验证结果、风险和未完成项。
- 核心功能：`HANDOFF_SUMMARY.md`、`FILE_MANIFEST.md`、Git 与非 Git 双场景、非 Git 基线与 SHA-256，以及二进制证据显式纳入。
- 本人承担：任务目标、边界、验收标准与最终判断。
- AI 辅助：整理步骤、生成材料和执行核验。
- 验证证据：unittest 9 项通过、七类隔离烟测通过，以及三张公开脱敏展示图。
- 项目边界：不自动替用户决策，也不替代 Codex 原生能力。

[查看项目详情](projects/codex-handoff-layer.md)

当前仅展示脱敏项目说明和截图，源代码与内部证据包暂未公开；如后续开源，应另建脱敏源代码仓库。
