# 建筑能源运行模式聚类与样例建筑画像分析（MVP）

## 1. 数据来源

项目目标：基于逐小时用电记录计算建筑负荷特征，并用固定规则生成建筑运行画像。

数据来自本地 BDG2 公开数据集文件（项目来源：`buds-lab` GitHub 仓库），数据覆盖 2016–2017 年，元数据含 1,636 栋建筑。实际检查到：`electricity_cleaned.csv` 有 17,544 条小时记录、1,578 个建筑用电列；`chilledwater_cleaned.csv` 有 17,544 条记录；`metadata.csv` 有 1,636 条建筑记录；`weather.csv` 有 331,166 条记录（均不含表头）。主分析仍只用用电数据；新增的冷冻水交叉验证见第 2 节末尾与 `output/chilledwater_crosscheck.csv`。用电列中的 1,578 个建筑 ID 均可在元数据中找到。

## 2. 方法

`feature_extract.py` 分块读取宽格式用电 CSV（每块 512 行），每个建筑输出一行。工作日均值按周一至周五的有效小时读数计算，周末均值按周六、周日计算。白天定义为小时 08:00–18:00（含 8 至 18 点），夜间定义为 00:00–06:00（含 0 至 6 点）；`day_night_ratio` 为这两个时段的均值之比。`peak_hour` 是该建筑 24 个小时平均负荷最高的小时；`max_value` 是全时段最大有效读数；`mean_value` 是全时段均值；`std_value` 是全时段样本标准差（ddof=1）；`peak_valley_diff` 是 24 个小时平均负荷曲线的最大值减最小值，不是逐日极差的平均值。

分类由 `classify_profile.py` 执行，不使用机器学习聚类。阈值固定如下；多个条件同时成立时按 A、B、C 的优先顺序归类：

- A 办公型：`weekday_mean >= 1.5 × weekend_mean`，且 `peak_hour` 在 8–18（含端点）。
- B 持续运行型（稳定运行模式：变异系数低，仅说明负荷曲线平稳）：`0.8 <= day_night_ratio <= 1.25`，且变异系数 `std_value / mean_value < 0.3`。
- C 夜间高负荷型：`night_mean >= 0.7 × day_mean`（由 `day_night_ratio <= 1 / 0.7` 判断），或者 `weekend_mean >= 0.8 × weekday_mean` 且峰值小时不在 8–18。
- D 其他型：不符合 A、B、C。用于规则比较的缺失值按条件不成立处理；零夜间均值对应无穷/未定义比例，不满足高夜间负荷条件。

`visualize.py` 根据原始用电数据重算选中建筑的 24 小时平均曲线，并绘制四类数量分布。A、B、C 各选择按 `building_id` 字典序最先的一栋作为样例建筑，图中展示该建筑所有有效记录按小时汇总的均值。图片使用 matplotlib，标题和坐标标签为英文，dpi=150。

缺失或无法转换为数值的用电单元格不填补，在各项统计中按有效读数跳过；没有有效读数时该项保留为空，除法分母为零时比例留空。全矩阵共计 2,471,853 个缺失/无法转换单元格（约 8.93%）。有 6 栋建筑没有全时段有效读数，因此 `mean_value` 和相关统计无法计算；分类条件缺失时按不满足处理。脚本将该计数打印到标准输出。

冷冻水交叉验证由 `chilledwater_check.py` 执行。脚本对冷冻水数据与用电数据共有的建筑列复用相同的特征提取定义和 A→B→C→D 固定规则，并将每栋共有建筑的用电类别与冷冻水类别逐一比较。结果写入 `output/chilledwater_crosscheck.csv`，按类别的数量对比图写入 `output/figures/power_vs_chilledwater.png`；交叉统计和一致率由脚本打印。

两份数据共有 541 栋建筑，其中 193 栋的分类字母相同，一致率为 35.67%（193/541）。在这 541 栋中，用电类别 A/B/C/D 分别为 46/193/172/130 栋，冷冻水类别 A/B/C/D 分别为 79/5/248/209 栋；交叉数量见脚本标准输出。

## 3. 发现

分类共覆盖 1,578 栋用电数据中出现的建筑：A 办公型 210 栋，占 13.31%；B 持续运行型（稳定运行模式：变异系数低，仅说明负荷曲线平稳）416 栋，占 26.36%；C 夜间高负荷型 603 栋，占 38.21%；D 其他型 349 栋，占 22.12%。C 类占比最高。在当前规则定义下，较多建筑表现出较高夜间负荷特征，需要结合建筑用途、运行计划和设备信息进一步判断。

## 4. 局限

分类阈值是人为设定的规则，结果会随阈值和优先顺序变化。缺失读数按有效观测跳过，可能影响均值、标准差、小时曲线和分类；未插补缺失值。主分类与曲线使用用电数据，冷冻水仅用于与用电结果交叉核对；天气或建筑类型等信息未纳入计算。分析仅覆盖用电文件实际包含的 1,578 栋建筑，元数据中的其余建筑没有用电列。各类别曲线图只展示每类按 ID 选出的单栋样例建筑，不代表该类整体。
